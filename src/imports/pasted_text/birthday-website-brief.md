Design a premium, romantic, cinematic birthday website for my girlfriend **Annu**.

This is a personal digital birthday gift, not a generic birthday website.

The design should feel like a combination of:

* A luxury digital photo album
* A romantic film
* A personal memory journal
* An interactive love letter

The experience should be emotional, elegant, intimate, and modern.

IMPORTANT:
Design the website mobile-first because Annu will primarily experience it on her phone. Also create a responsive desktop version.

==================================================
BRAND / VISUAL DIRECTION
========================

Overall mood:
Romantic, cinematic, dreamy, elegant, emotional, warm.

Color palette:

* Deep burgundy / wine
* Dark charcoal
* Warm ivory / cream
* Soft blush pink
* Very subtle champagne/gold accents

Avoid:

* Cartoonish birthday graphics
* Excessive hearts
* Neon colors
* Generic birthday templates
* Overly bright pink
* Cluttered layouts

Use subtle decorative elements:

* Small floating hearts
* Tiny stars
* Soft grain
* Subtle glow
* Elegant gradients
* Very light particles

Typography:

* Elegant editorial serif font for major headings
* Clean modern sans-serif for body text
* Large expressive typography for emotional moments

Use generous spacing and strong visual hierarchy.
